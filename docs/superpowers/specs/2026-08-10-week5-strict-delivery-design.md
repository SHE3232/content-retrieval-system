## 严格完成定义

第五周最终状态只允许使用以下结论：

- `完成`：本设计规定的功能、平台、工具、可用性测试和交付物均有实际证据。
- `受阻`：外部平台、设备、人员或工具不可用，导致任一强制验收无法执行。
- `未完成`：已经具备执行条件，但实现、测试、整改或文档仍未达到验收门槛。

不得使用“基本完成”“源码应可构建”“计划已覆盖”代替实际构建和验证证据。

## 功能架构

Flutter 应用使用小型、可测试的分层边界：

```text
Material 3 页面与无障碍组件
              ↓
页面 Controller / View State
              ↓
API Client、设置仓库、平台文件打开适配器
              ↓
本地 FastAPI + 系统平台能力
```

- 页面组件不直接拼接 HTTP 请求或启动系统命令。
- Controller 负责请求版本、加载、成功、空结果、失败和离线状态。
- API Client 只映射后端公开契约和安全错误字段。
- 设置仓库负责持久化和损坏数据回退。
- 文件打开适配器使用参数数组调用平台程序，不通过 Shell 字符串拼接。
- 无障碍语义、焦点和状态播报在组件边界内测试。

## 核心用户流程

### 文件库流程

```text
选择目录 → 提交索引任务 → 轮询进度 → 展示结果/失败
    ↓                                  ↓
目录列表 ← 删除 / 强制重建 / 打开文件 ← 文件详情
```

### 搜索流程

```text
输入查询 → 选择通道和过滤器 → 请求搜索 → 结果/空状态/错误
                                      ↓
                              打开文件或复制路径
```

### 设置流程

```text
读取本地设置 → 应用主题与无障碍偏好 → 用户修改 → 原子持久化
       ↓
数据损坏时恢复默认值并显示可操作提示
```

## 无障碍实现要求

- 所有输入、按钮、导航目标、筛选器和状态具有名称、角色、值和状态。
- 在线、离线、成功、警告和失败同时提供文字，不只依赖颜色。
- Tab 顺序符合视觉和任务顺序，Modal、抽屉和对话框正确约束并恢复焦点。
- Enter、Space、Escape、方向键和约定快捷键具有一致行为。
- 所有键盘焦点均有清晰可见的焦点样式。
- 普通文本对比度不低于 4.5:1；大文本和 UI 图形不低于 3:1。
- 200% 字体缩放下不裁切文字、不遮挡操作、不丢失信息。
- 高对比度模式改变完整语义色板，而不是只反转背景颜色。
- 系统要求减少动画时关闭非必要进入和装饰动画。
- 异步索引、搜索完成、失败和后端状态变化向辅助技术播报，但避免重复播报。

## 自动化与 E2E 验收

所有 Flutter 代码必须通过：

```text
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

真实 E2E 使用 TXT、PDF、DOCX、JPG、PNG 五种输入，至少覆盖：

1. 添加本地目录并完成索引。
2. 查看进度、成功结果和失败详情。
3. 执行关键词、文本语义、图片语义和混合检索。
4. 使用格式和模态过滤。
5. 打开文件和复制路径。
6. 删除索引并确认结果消失。
7. 强制重建并确认结果恢复。
8. 重启后端并确认索引和设置保持。

## 可用性测试设计

至少 3 名参与者完成以下任务：添加目录、找到指定文档或图片、修改过滤条件、删除并
重建索引、调整高对比度和字体大小。至少一轮完整使用纯键盘；条件允许时包含实际屏幕
阅读器用户。

记录任务完成率、完成时间、错误次数、求助次数和主观反馈。阻止核心任务完成的问题
属于严重问题，必须修复并复测；未复测不得关闭。

## 错误处理

必须覆盖后端离线、请求超时、请求校验失败、索引部分失败、索引任务异常失败、文件不
存在、系统拒绝打开文件、设置数据损坏和平台能力不可用。

用户可见错误包含三个部分：发生了什么、可能原因、恢复操作。界面不得显示后端堆栈、
内部对象表示或未经处理的系统异常。

后端离线时保留已经加载的结果和设置，只禁用需要新请求的操作。晚到的旧请求不得覆盖
新请求状态。索引变更操作串行化，避免删除、重建和检索刷新相互覆盖。

## 外部阻塞与最终判定

以下任一条件成立时，总计划状态为 `受阻`：

- 无可用 Mac 执行 macOS 构建和 VoiceOver。
- 无可用 Linux 环境执行 Linux 构建与 smoke。
- 无 Android SDK、模拟器或真机执行 Accessibility Scanner。
- WAVE 无法运行或无法保存可复核结果。
- 无法组织最低人数的可用性测试。

外部阻塞只影响最终完成判定，不阻止在可用环境中继续实现、测试和整理证据。

## 不在第五周范围

- Windows、macOS、Linux 的正式安装包签名和公开发布。
- Android 或 Web 的生产级完整功能和发布。
- Python 推理运行时迁移到 TensorFlow Lite。
- 第六周的全系统压力测试、性能优化和安全审查。
- 第七周的完整维护指南、开源合规和最终 UI 抛光。
- 第八周的正式三平台发布、演示视频和作品集包装。
